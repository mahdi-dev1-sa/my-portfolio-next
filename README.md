# my-portfolio-next

Portfolio built with Next.js and Tailwind CSS.

- Colors: black 60% + purple 30% + a random accent (lime, cyan, magenta, orange) 10%
- Preloader with a counter and animated capsules
- Pull cord (top right) with rope physics toggles light and dark mode, with a circle reveal

Live: https://mahdi-dev1-sa.github.io/my-portfolio-next/
